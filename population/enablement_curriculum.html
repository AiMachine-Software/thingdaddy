01Module 1 · The Model

Everything ThingDaddy does rests on one move: give a physical thing a stable, non-fabricated name. That name is a GS1 URN. Learn to read it and you can read the whole system.

1.1 · Anatomy of a URN

Every identity is written the same way. Read this one aloud:

urn:epc:id:sgtin:0614141.012345.62852
└─ scheme ──┘ │      │        │       └─ serial number (this one pack)
              │      │        └─ item reference (which product)
              │      └─ GS1 company prefix (the WHO — never derived)
              └─ identity type (here: a serialized trade item)
The load-bearing rule, taught first. The company prefix is the root — the who. We never fabricate it and never derive where it ends (it is variable-length). If we don't know it, the identity is a candidate, never a guess. Everything else in the course depends on this one habit.

Teaching note: the prefix 0614141 above is GS1's textbook example prefix — perfect for a lesson, never for the real registry. Rooting a live record on it would be exactly the fabrication we refuse. That distinction — example vs verified — is the first reflex to build.

1.2 · The seven identities

One prefix, many identity types. Each answers a different question about the same physical world:

GroupTypeIdentifiesExample URN
ProductGTIN / SGTINa product / one serialized uniturn:epc:id:sgtin:…
ProductCPIa component or parturn:epc:id:cpi:…
ProductLGTINa lot or batchurn:epc:id:lgtin:…
LocationGLN / SGLNa place — this is the ThingSiteurn:epc:id:sgln:…
LogisticsSSCC / GSINa shipping container / a shipmenturn:epc:id:sscc:…
AssetsGIAI / GRAIa fixed asset / a returnable asset (a pallet)urn:epc:id:grai:…
Service & otherGSRN / GDTIa person or agent / a documenturn:epc:id:gdti:…

Notice the shape: an instrument is a GIAI, its components are CPIs, its consumables are SGTINs, the protocol it runs is a GDTI, the lab it lives in is a GLN, the agent who runs it is a GSRN. A whole working node, in six identity types. That is the node we build for real.

1.3 · A ThingSite is a place, not a company

This is the idea most people get wrong first. A website replicates — one corporate site copied across geographies, differentiating nothing. A ThingSite is bound to a GLN, so every physical place is its own ThingSite. Every Thermo Fisher office (Pittsburg, Marietta, Asheville, Fremont) carries a different prefix and is a different ThingSite. Every Novartis lab is a different ThingSite. A company doesn't get a ThingSite — it brings its map of locations when it claims them, and consents to each at the moment of claim.

Check yourself (Module 1). (1) Read urn:epc:id:giai:0614141.17320508 aloud and name every part. (2) Which identity type is a pallet, and why is it "returnable"? (3) A vendor has 40 labs worldwide — how many ThingSites, and what do they bring to claim them? (4) Why is 0614141 fine on this page but forbidden in the live registry?
