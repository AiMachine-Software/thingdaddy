ThingDaddy

GS1 EPC URN identity registry, agent fleet, and Physical-AI graph. Static pages served from this repository via GitHub Pages.

Runs here (static)

  • Demo screens S1 – S6Panels are labelled LIVE or FIXTURE. On GitHub Pages there is no API, so every panel shows FIXTURE data.
  • ConsoleSame deployable demo, console view. FIXTURE mode on Pages.
  • ConfiguratorSelf-contained page, no backend needed.
  • Screens S1 – S6 (fill variant)Earlier version of the demo screens kept under population/fill.
  • General Atomics · ThingSiteGenerated ThingSite page for one company, fully static.

Needs the local backend (will not load data on Pages)

  • HomeCalls /api/companies_full. Shows "engine unreachable" without the API.
  • ThingSiteCalls the population API for prefix lookup and search.
  • DemoHard-wired to http://127.0.0.1:8793, local machine only.

Run the full app locally

  • Docker Desktop, then from the repo root:docker compose -f web/docker-compose.yml up -d --build and open http://localhost:8789/. See web/README.md.
